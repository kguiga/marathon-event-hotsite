# 🏃 Marathon Event Hotsite

## 📖 Descrição

Projeto de desenvolvimento web criado para divulgação e gerenciamento de inscrições de uma maratona esportiva.

O sistema foi desenvolvido utilizando HTML5, CSS3 e JavaScript, contemplando múltiplas páginas, formulário de inscrição com validações, cálculo automático de IMC, galeria de imagens, contador regressivo para o evento, FAQ e exibição de documentos em PDF.

O projeto teve como objetivo aplicar os principais conceitos de desenvolvimento front-end, criação de interfaces responsivas e interação com o usuário através da manipulação do DOM.

---

## 🎯 Objetivos

- Desenvolver um website multipágina utilizando HTML, CSS e JavaScript.
- Aplicar conceitos de design responsivo.
- Construir formulários com validação de dados.
- Implementar funcionalidades dinâmicas utilizando JavaScript.
- Trabalhar manipulação de elementos do DOM.
- Criar componentes interativos para melhorar a experiência do usuário.

## 🖼️ Recursos Interativos

### Contador Regressivo

Exibição dinâmica do tempo restante para a realização do evento.

### Galeria com Modal

Visualização ampliada das imagens através de janela modal.

### Slider Automático

Rotação automática de imagens na página principal.

### Cálculo de IMC

Cálculo automático do Índice de Massa Corporal (IMC) a partir dos dados informados pelo participante.

### Validação de Formulário

Validação de campos obrigatórios e regras de participação antes do envio dos dados.

## ▶️ Como Executar

Clone o repositório:

```bash
git clone https://github.com/kguiga/marathon-event-hotsite.git
```

Acesse a pasta do projeto:

```bash
cd marathon-event-hotsite
```

Abra o arquivo principal:

```bash
index.html
```

Ou utilize uma extensão como **Live Server** no VS Code para executar o projeto localmente.
